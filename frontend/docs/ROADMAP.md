# Roadmap

1. **PR1 — Foundation/domain model**: types, validation, persistence additions, documentation.
2. **PR2 — Basic deterministic progression engine**: rep/load progression with explicit rationale codes.
3. **PR3 — Recommendation UI + Why?**: concise prescription plus inspectable explanation.
4. **PR4 — Subjective readiness**: soreness, fatigue, motivation, stress, pain, unusual events.
5. **PR5 — HealthKit recovery ingestion**: sleep, resting HR, HRV, steps, active energy.
6. **PR6 — External workout classification**: BJJ, running, swimming, cycling, sport.
7. **PR7 — Multi-sport fatigue model**: affected regions and interference-aware adjustments.
8. **PR8 — Mesocycles/deloads**: accumulation, deload triggers, block-level progression.
9. **PR9 — Analytics**: e1RM, rep PRs, volume, adherence, readiness and recovery trends.
10. **PR10 — Optional AI coach**: explanations, strategic review, natural-language queries.
